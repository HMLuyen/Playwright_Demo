# CLAUDE.md

Project-specific instructions for this repo.

## Git

- Do not squash/amend existing commits into one. Make a new commit for each round of changes, not `git commit --amend` by default. Only squash/amend when explicitly asked, for that instance.
- Never add a `Co-Authored-By` line to commit messages.
- Never run `git add`/`git commit` unless explicitly asked to commit.
